## About

Joyful Jaw is a research resource for evaluating clinical reasoning and explainability in large language models for temporomandibular disorders. Its aim is to make a model's reasoning process, and the evidence behind its outputs, inspectable — rather than judging a model by answer accuracy alone.

The project is intended for research and pre-deployment benchmarking. It is not a clinical tool, and nothing in this repository is intended for clinical use.

Detailed methods and findings are not described here, as the manuscript has not yet been published.
